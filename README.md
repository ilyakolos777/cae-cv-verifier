##  Описание алгоритма

Верификация осуществляется за счет параллельной работы физического и математического контуров:
1. **Сбор физических данных:** Микроконтроллер ESP32-CAM транслирует MJPEG-видеопоток деформируемого образца по локальной сети.
2. **Оптический трекинг:** Библиотека OpenCV распознает контрастные fiducial-маркеры (ArUco), нанесенные на образец. Происходит вычисление евклидова расстояния между начальными и текущими центрами маркеров.
3. **Калибровка (Пиксели -> мм):** На основе известного физического размера эталонного маркера система вычисляет масштабный коэффициент и переводит пиксельные смещения в миллиметры.
4. **Математическое моделирование (МКЭ):** Встроенный решатель (Solver) формирует глобальную матрицу жесткости детали, накладывает граничные условия и вычисляет вектор теоретических узловых перемещений при заданной нагрузке.
5. **Анализ:** Система сопоставляет массивы реальных и теоретических координат, выводя графики абсолютной погрешности в реальном времени.

##  Архитектура модулей

Проект построен по модульной архитектуре с разделением вычислительного ядра и графического интерфейса:

* **`main.py`** — точка входа. Содержит QThread-воркер для асинхронного выполнения тяжелых расчетов (OpenCV + МКЭ) без блокировки интерфейса.
* **`core/` (Вычислительное ядро)**
  * `camera.py` — захват, парсинг бинарных чанков и декодирование MJPEG-потока.
  * `tracker.py` — пайплайн компьютерного зрения: инициализация словаря ArUco, детекция углов, расчет векторов смещения.
  * `solver.py` — математический модуль МКЭ (расчет матриц упругости и жесткости, решение системы уравнений $KU = F$).
  * `mqtt_client.py` — асинхронный клиент для приема телеметрии и отправки команд управления на ESP32.
* **`ui/` (Графический интерфейс на PyQt6)**
  * `main_window.py` — компоновка элементов рабочего стола и боковой панели.
  * `custom_controls.py` — глобальные QSS-стили (современная темная тема).
  * `video_widget.py` — виджет для высокопроизводительного рендеринга обработанных кадров с наложением маркеров.
  * `charts_widget.py` — интеграция `pyqtgraph` для отрисовки эпюр и графиков погрешности в реальном времени.
* **`utils/exporter.py`** — модуль формирования и выгрузки Excel-отчетов с использованием `pandas` и `openpyxl`.
* **`config/settings.py`** — конфигурационный файл (IP-адреса, топики MQTT, физические константы материала).

##  Требования и оборудование

**Аппаратная часть:**
* Микроконтроллер ESP32-CAM.
* Локальный MQTT-брокер (рекомендуется *Eclipse Mosquitto*, IP должен быть прописан в `settings.py`).

**Программная часть:**
* Python 3.11 или выше.
* Установленные зависимости из `requirements.txt`.

##  Установка и запуск

1. Клонируйте репозиторий на локальную машину:
   ```bash
   git clone https://github.com/ilyakolos777/cae-cv-verifier.git
   cd cae-cv-verifier
   
2. Создание и активация виртуального окружения:
   ```bash
   # macOS / Linux
   python3 -m venv .venv
   source .venv/bin/activate
   
   # Windows
   python -m venv .venv
   .venv\Scripts\activate

3. Установка зависимостей:
   ```bash
   pip install --upgrade pip
   pip install PyQt6 pyqtgraph

4. Отредактируйте файл `config/settings.py`, указав актуальные IP-адреса камеры и MQTT-брокера.

##  Руководство пользователя

### Шаг 1: Подготовка стенда
* **Монтаж:** Надежно закрепите натурный образец в захватах испытательной машины.
* **Оптика и свет:** Убедитесь, что нанесенные ArUco-маркеры равномерно освещены (без резких бликов), а объектив ESP32-CAM сфокусирован строго на плоскости детали.

### Шаг 2: Инициализация системы
* Запустите приложение из терминала:
  ```bash
  python main.py
  ```
* В левой панели навигации нажмите кнопку ** Запуск потока** (или **РАССЧИТАТЬ**).
* *Ожидаемый результат:* Программа подключится к микроконтроллеру по сети MQTT/HTTP и выведет видеопоток в главное окно.

### Шаг 3: Калибровка масштаба
* Дождитесь появления цветных осей и контуров поверх маркеров на видео — это означает успешный захват целей модулем OpenCV. 
* Программа **автоматически** зафиксирует базовые начальные координаты и рассчитает переводной коэффициент из пикселей в миллиметры.

### Шаг 4: Проведение испытания
* Начните плавно увеличивать физическую нагрузку на образец.
* Следите за блоком визуализации: система будет в реальном времени строить графики фактической деформации (CV) и сопоставлять их с расчетной линией МКЭ (CAE), выводя дельту погрешности.

### Шаг 5: Выгрузка результатов
* После снятия нагрузки нажмите кнопку ** Экспорт отчета (Excel)**.
* *Сохранение:* Сгенерированная таблица с покадровой сводкой перемещений и рассчитанными погрешностями появится в рабочей директории проекта:
  ```text
  data/reports/
  ```
